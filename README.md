# Wildlife Conservation Monitoring Database Management System

## Project Description

This project was developed for the CMPE344 / Database II course.

The system is designed to help manage and monitor wildlife conservation activities through a user-friendly interface and database management techniques.

## Features

* Animal management
* Species monitoring
* Ranger management
* Wildlife sighting records
* User login system
* Dashboard interface

## Technologies Used

* HTML
* CSS
* JavaScript
* Database Management Concepts
* GitHub

## Project Files

* animals.html
* dashboard.html
* login.html
* operations.js
* rangers.html
* sightings.html
* species.html
* style.css
* users.html

## Purpose of the Project

The purpose of this project is to improve wildlife monitoring, data organization, and conservation tracking using database management concepts.
